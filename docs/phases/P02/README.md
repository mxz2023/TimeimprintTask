## 2. 目标与范围

P02必须完成：

- 每个模块先按业务功能、再按技术职责组织包，严格使用02的模块映射；源码路径与`package`完全一致。
- 测试源码使用与生产源码完全相同的包路径；每个顶层生产类型具有一个可识别、非空的所有者测试。
- 对承担多个独立职责的大类，先建立特征测试，再按职责拆分；拆分不得改变可观察行为。
- 通过自动化架构规则持续阻止平铺包、泛化`impl/util/misc`目录、路径错位、测试镜像缺失和所有者测试遗漏。

本阶段不新增业务场景或能力。S01、S02以及CAL-01—CAL-05、NOT-01—NOT-03保持RELEASED / VERIFIED；其他条目的三维状态保持不变，因此场景与能力准入对本工程维护阶段不适用。
