## 2. 已接受口径

| 口径 | 结论 |
| --- | --- |
| 场景 | 新增 `maintenance`，放在现有到期模块。不改 S02 固定锚点 |
| 完成 | 实例命令 `complete`，载荷为空。完成日是命令当天的北京时间日期。同一实例再次完成不推进 |
| 间隔 | 正整数自然日。延迟完成从实际完成日起算。三个月写成调用方给出的天数 |
| 未完成 | 到期日只提醒，不自动滚到下一次 |
| 跳过 | 不提供跳过命令，锚点保持不变 |
| 暂停 / 退役 | 沿用平台控制。暂停不产生新提醒。已记下的完成日保留 |
| 数据 | 一条持续定义。完成后更新同一对象的下一次日期，并留下完成历史 |
| 提醒 | 下一次到期日当天提醒一次，实例保持等待直到完成 |
| 日历 | 复用 `ANCHOR_OFFSETS` 且偏移只有 0。完成时替换该绑定锚点 |
| 内核与公共表 | 不改 kernel 业务语义，不改平台公共表结构 |
