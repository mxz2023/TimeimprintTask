## 2. 要解决的问题

网页登录已经走 TimeImprintUser 的 `/api/v1/users/**`，新账号写在 `tu_*`。任务接口仍用 Task 自己的 `tt_identity_*` 解析令牌。两边的账号和令牌没有打通，所以新登录的用户打不开自己的任务。

P11 要让迁移前已经存在的账号继续登录，并访问自己原来的任务。已签发且未退出的令牌在迁移后仍然有效。退出、停用后，令牌立即失效。
