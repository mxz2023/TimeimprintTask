# Review 报告目录

`docs/review/` 保存代码审查报告，便于按时间追溯审查范围、发现和当时的验证结果。

## 命名规则

- 文件名格式：`YYYY-MM-DD-HHmmss-主题.md`。
- 时间统一使用 `Asia/Shanghai` 时区，精确到秒。
- 同一主题再次审查时新增报告，不覆盖历史报告。

## 权威边界

- 报告是审查时点的历史快照，不是需求、契约、任务状态或交付状态的权威来源。
- 需要长期生效的结论应迁入对应的正式契约、场景、能力、阶段、ADR 或验收文档。
- 任务状态以当前阶段的 `README.md` 和 `IMPLEMENTATION.md` 为准；验证完成证据只记录在当前阶段的 `DELIVERY.md`。
- 报告中的问题修复后，应通过新的复审报告记录结果，并同步维护正式阶段文件。
